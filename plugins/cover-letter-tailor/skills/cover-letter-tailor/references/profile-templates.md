# profile/ 欄位範本

`profile/` 裡每個檔的格式。Mode 0 轉正、Mode 2 新增條目都照這裡。
欄位沒有資料時寫「無」，而且必須是使用者自己說「無」；不要自己補。
日期一律 `YYYY-MM`（時間）或 `YYYY-MM-DD`（last_confirmed）。

Mode 1 引用證據時寫 `profile/<檔名>:L<行號>` 加原句，所以**每個事實獨立一行**，
不要把兩件事塞進同一行。

---

## resume.md

```markdown
# 學經歷

## 經歷

### <單位>｜<職稱>
- 時間：YYYY-MM – YYYY-MM（還在就寫「至今」）
- 單位：<公司或組織全名>
- 職稱：<職稱>
- 職責：
  - <一件事一行>
  - <一件事一行>
- 成果數字：
  - <一個數字一行，寫清楚是什麼的數字、比較基準是什麼>
- last_confirmed: YYYY-MM-DD

## 學歷

### <學校>｜<學位與科系>
- 時間：YYYY-MM – YYYY-MM
- 單位：<學校全名>
- 職稱：<學位／科系／組別>
- 職責：<研究方向、論文題目、主要修課、社團或助教職務>
- 成果數字：<GPA、排名、獎項、論文發表；沒有就寫「無」>
- last_confirmed: YYYY-MM-DD
```

學歷沿用同一組欄位，好讓 Mode 2 用同一套問法核對：「職稱」放學位與科系，
「職責」放研究與修課，「成果數字」放成績與獎項。

經歷與學歷各自由新到舊排。

## projects/<slug>.md

一個專案一檔。`<slug>`：短、無空白，可以用中文，例如 `會員系統改版.md`。

```markdown
# <專案名稱>
- 背景：<為什麼有這個專案、當時的問題是什麼>
- 我的角色：<個人／團隊幾人中負責什麼>
- 做了什麼：
  - <一件事一行>
- 技術或方法：<工具、語言、框架、方法論>
- 結果（數字）：
  - <一個數字一行；沒有數字就寫「無」>
- 證據連結：<repo、作品頁、報告檔路徑；沒有就寫「無」>
- last_confirmed: YYYY-MM-DD
```

已結束的專案在「背景」行尾加「（已於 YYYY-MM 結束）」。

## skills.md

```markdown
# 技能與證照

熟練度三級：會用／做過產品／能教人。生疏了在後面加「（已生疏）」。

## 技能

### <分類，例如：程式語言>
- <技能>｜<熟練度>｜last_confirmed: YYYY-MM-DD
- <技能>｜<熟練度>（已生疏）｜last_confirmed: YYYY-MM-DD

### <分類，例如：工具與平台>
- <技能>｜<熟練度>｜last_confirmed: YYYY-MM-DD

## 證照
- <證照名稱>｜<發證單位>｜取得 YYYY-MM｜<有效期限或「無期限」>｜last_confirmed: YYYY-MM-DD
```

分類依實際內容決定，不要硬套。

## writing_sample.md

```markdown
# 寫作樣本

來源：<使用者貼上／raw/<檔名> 的自傳段落，經使用者確認>
日期：YYYY-MM-DD

<使用者自己寫的一段文字，原文照貼，不改字>
```

只用來抓語氣（句長、正式程度、連接詞、怎麼開頭），內容不進信。

## CHANGELOG.md

```markdown
# CHANGELOG

新的在上面。條目寫成「<檔名> › <條目標題>」。

## YYYY-MM-DD（模式 <0／2>）

- **resume.md › <單位>｜<職稱>** — <欄位>
  - 改前：<原值>
  - 改後：<新值>
- **projects/<slug>.md › <專案名稱>** — 新增
  - 改前：（無）
  - 改後：（新條目，全文見該檔）
- **skills.md › <技能>** — 刪除
  - 改前：<整條原文，刪掉後只剩這裡有>
  - 改後：（刪除）
- **以下全部正確**：<條目1>、<條目2>、<條目3> — last_confirmed <舊日期> → <今天>

## raw/ 快照

Mode 0 每次跑完整張重寫。Mode 0 的「之後再執行」和 Mode 2 的新檔提醒都靠這張表判斷哪些檔處理過。

| 檔名 | 大小（bytes） | 修改時間 | sha256 前 12 碼 | 版本日期 | 日期來源 | 處理日期 |
|---|---|---|---|---|---|---|
| <檔名> | <大小> | YYYY-MM-DD HH:MM | <12 碼> | YYYY-MM-DD | 檔內／修改時間 | YYYY-MM-DD |
| <檔名> | — | — | — | — | 未讀取（<原因>） | YYYY-MM-DD |
```

`raw/ 快照` 永遠放在檔案最後，日期段落往上加。
