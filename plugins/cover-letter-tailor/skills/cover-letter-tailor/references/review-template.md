# REVIEW.md 範本

Mode 0 寫在 `profile/REVIEW.md`。第一次跑用 A，之後只處理新檔時用 B。
這是草稿：Mode 1 不讀它，它也不算 profile 的一部分。

---

## A. 第一次整併

